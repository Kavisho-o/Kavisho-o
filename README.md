### 🔎 GitRAG
**GitHub Codebase RAG Assistant**

Answers questions about any public repository in plain English, with cited, source-traceable answers.

- Code-aware chunking via `tree-sitter` at real function/class boundaries
- Multi-query hybrid retrieval (BM25 + vector) with CrossEncoder reranking
- **100% success rate** on 10 held-out questions (SQLModel repo, 667 chunks)
- Agentic pipeline (LangGraph) deployed as a FastAPI service on Render

### ⚡ AI-Inference-Gateway
**Multi-Provider LLM Routing Layer**

Multi-provider LLM gateway with automatic failover, rate limiting, and cost tracking.

- Routes across **5 providers** (Groq, OpenAI, Anthropic, Gemini, Ollama) with per-provider circuit breakers
- Token-bucket rate limiting and request-hash response caching
- Retryable vs. non-retryable failure separation to preserve retry budget
- Benchmarked latency and cache hit rate under concurrent load
